# REVIEW QA — 17 Agustus 2026

Audit QA menyeluruh read-only backend + frontend. Metode sesuai alur trust-but-verify: baca seluruh dokumen acuan (`docs/`) → petakan struktur → delegasi 3 sub-agent paralel (scope A/B/C) → **setiap klaim TINGGI diverifikasi ulang langsung ke source**. Tidak ada perubahan kode.

**Konteks teknis sesi ini:** 3 sub-agent pertama gagal karena admission-homelab OmniRoute (`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=1` → 503). Dilebarkan ke **4** (env container) → sub-agent ketiga lolos. Tidak menyentuh aux.

Cakupan: backend ~5.873 LOC controller + 458 test/scripts + 725 LOC SQL; frontend ~7.412 LOC pages + 5.311 LOC components + 1.021 LOC test.

## 2. Hal yang sudah bagus (terverifikasi)

- **XSS bersih** — nol sink `dangerouslySetInnerHTML|srcDoc|eval|innerHTML=` di seluruh frontend; chat dirender teks polos; token tidak pernah di localStorage.
- **Single-flight refresh** benar-benar berfungsi (`authMiddleware.js:49-72`) — race logout paksa tertutup; cookie httpOnly+secure+sameSite benar; `isSeller` baca role dari DB.
- **Hanya percaya `req.user.uid`** — tidak ada path auth/profile membaca UID dari body/query/params; seluruh endpoint ter-guard.
- **Webhook Midtrans** — signature sha512 benar, mapping `-RETRY-` benar, idempoten, "guard paid" melindungi order lunas (kekurangannya T4).
- **State machine seller ketat** — transisi tak valid ditolak 400; cancel hanya dua status awal + restore stok.
- **Rating anti-spam** — order milik user + produk ada di order + COMPLETED + unique(user,product,order) + agregat atomik.
- **Multi-toko** — 4 titik authz benar (`items.some()` + filter SQL `@>` GIN); NEW_ORDER/ORDER_CANCELLED ke SEMUA seller.
- **Produk** — batas harga/stok + whitelist kategori di create & update.
- **Routes 100% coverage** — 48 endpoint terdaftar semua menunjuk fungsi yang ada; urutan param route benar.
- **Chatbot** tidak log API key; authz partisipan chat ketat; CORS ketat.
- Frontend: uang dihitung server-side, debounce+cleanup toko, interceptor di-eject saat unmount, fallback gambar offline, test 39 tanpa `.skip`/`.only`, fake timers utk isolasi timer 3s.

## 3. TIDAK TERVERIFIKASI (perlu uji/investigasi)

- Privasi bucket storage `orders` (policy storage tak ada di repo — hanya `createSignedUrl`).
- Grants RPC anon (`create_order`/`cancel_order`/`add_rating` bisa dipanggil langsung via PostgREST? tak ada revoke).
- Perilaku riil Snap token reuse pada order `PAYMENT_FAILED` (#22).
- Runtime: `npm test`/build/BUILD tidak dijalankan — audit murni statis.
- Timing-based enumeration forgot-password (jalur terdaftar lebih lambat).
