## Temuan & Perbaikan (REVIEW ini)

### 🔴 A — Race double-restore stok di `cancel_order` (HIGH)
- **Lokasi**: `backend/supabase/order-functions.sql` (`cancel_order`, baris ~123-161)
- **Masalah**: `cancel_order` membaca `v_order` tanpa `FOR UPDATE`, lalu mengembalikan
  stok. Dua request cancel paralel untuk order yang sama → keduanya baca stok lama →
  restore ganda → stok produk inflasi (> stok riil) → over-sell / data rusak. Ini
  kebalikan bug T3 yang SUDAH diperbaiki di `create_order` (pakai `FOR UPDATE`).
- **Bukti**: `search_files` konfirmasi `for update` hanya ada di `create_order:38`, tidak
  di `cancel_order`.
- **Fix**: migration baru `backend/supabase/migrations/20260823_cancel_order_race_fix.sql`
  — `cancel_order` diubah pakai `FOR UPDATE` saat restore stok + **idempotensi**: jika
  order sudah `CANCELLED`, restore dilewati (tidak dobel). Pola disamakan dengan `create_order`.
- **Wajib apply manual** ke Supabase (SQL Editor) — Supabase tidak auto-run file di folder
  `migrations/`. Cek `backend/docs/SUPABASE_MIGRATIONS.md` jika ada.

### 🔴 B — Midtrans Server/Client Key tercetak ke log (HIGH)
- **Lokasi**: `backend/src/config/midtransConfig.js:8-19`
- **Masalah**: `console.log` mencetak 10 karakter pertama `MIDTRANS_SERVER_KEY` &
  `MIDTRANS_CLIENT_KEY` (ROADMAP #12 sasaran "hapus total" — sebelumnya masih ada).
- **Fix**: hapus seluruh blok `console.log` inisialisasi key. Modul tetap ekspor `snap`
  dengan key dari env (tanpa log).

### 🟠 C — OMNIROUTE_API_KEY tercetak ke log (MEDIUM)
- **Lokasi**: `backend/src/controllers/chatbotController.js:260`
- **Masalah**: `console.error`/`log` mencetak `Authorization: *** ${OMNIROUTE_API_KEY}`
  → API key terekspos penuh di log.
- **Fix**: hapus log tersebut; header jadi `Authorization: \`Bearer ${OMNIROUTE_API_KEY}\``
  (langsung dari const, tanpa dicetak ke log).

### 🟠 D — Path traversal di `extractPathFromPublicUrl` (MEDIUM)
- **Lokasi**: `backend/src/utils/storageHelper.js:58-64`
- **Masalah**: tidak menolak `..` / skema absolut → potensi ekstrak/delete file luar bucket.
- **Fix**: tolak path berisi `..`, `//`, skema absolut (`https:` dll), dan path diawali `/`.
  Path hasil ekstrak harus relatif & tidak mengandung segmen traversal.
