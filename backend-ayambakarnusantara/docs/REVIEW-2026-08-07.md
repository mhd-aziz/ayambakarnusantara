- Sort-by-name hanya dalam 1 halaman (paginasi tidak bersambung).
- `profileController`/`productController`/`shopController` hapus gambar lama **sebelum** upload baru → gagal upload = gambar hilang.

- `profiles_select` RLS `using(true)` — PII (email/phone/address) terbaca via anon key.
- `cancelOrder` notifikasi hanya `items[0].shopId`.

## 4. Hal baik yang terverifikasi

- RLS aktif di semua 12 tabel; data privat ber-policy "own"; insert publik hanya rating/feedback.
- `isSeller` cek role dari DB (bukan JWT claim) → selalu aktual.
- Cookie httpOnly+secure; auto-refresh 7 hari; `deleteUser` bersih (storage + percakapan).
- Semua 30+ endpoint punya wrapper service (tidak ada yang hilang); `withCredentials` konsisten.
- XSS aman (tanpa `dangerouslySetInnerHTML`); token tidak di localStorage.
- Chat authz partisipan ketat; chatbot hanya akses order milik user.
- Formula `{success,message,data}` konsisten; order state machine sesuai business-flow; rating anti-spam & agregat atomik.
- **Alur bisnis & alur kerja website tidak diubah** pada seluruh rangkaian fix ini.
